# 连接中心（源 ⇄ 工具 绑定矩阵）· 重构方案

> 2026-11-02 · 状态：待评审 · 原型：`原型/连接中心-矩阵-画布.html`
> 需求原文：① 远仓也要加入连接工具的能力；② 重构整个交互——简单、直接、逻辑清晰、不要有太深的下钻，统一动效；③ 双向多对多：多目录绑多工具，反之亦然。

---

## 1. 对现状的诊断

当前（v1 目录绑定）的问题：

| 问题 | 现状 |
|---|---|
| 下钻太深 | Skills 页 → 目录管理弹窗 → 行内「连接工具…」→ 连接弹窗，共 3 层 |
| 只有一个方向 | 只有「目录 → 工具」；工具视角看不到自己接了哪些源 |
| 远仓缺位 | 只有本地目录能绑定；远仓（拉取条目）只能手动逐条分发 |
| 交互不统一 | 建连/断开/暂停散落在三个弹窗里，动效各自为政 |
| 关系不可见 | 连接关系藏在弹窗行内 chips 里，无法一屏总览 |

## 2. 核心决策

1. **一级视图「连接」**：与 会话/Skills/MCP/设置 并列的新入口（跨目录/远仓/工具的横向能力配得上一级入口）。主体 = **源 × 工具 绑定矩阵**。
2. **统一「源」抽象**：本地目录与远程仓库同权——都是「可绑定的源」。
   - 本地目录源：同步 = 目录内全部登记条目（现有 dir_bindings 语义）；
   - 远仓源：同步 = 该源「已拉取到本地库」的条目（registry_items.source_id=N）；上游更新 → 拉取 → 同一 worker 链路自动分发。
3. **绑定对象仍是 target（目标目录）**：共享 skills_dir（Codex/OpenCode 同路径）以「共享」标注明示。
4. **零下钻**：矩阵格是唯一交互载体——点空格建连（一层原位浮窗：写入方式+冲突策略）、点已连格管理（同步/断开）、悬停看状态。原「目录管理 → 连接工具…」入口废弃，目录管理弹窗回归纯目录职责。
5. **统一动效**：一条曲线（.2,.6,.3,1）+ 两档时长（150/250ms）+ 四种语义（连接=描边生长+填充、断开=淡出、同步中=单次扫光、失败=黄底常亮）。自动同步不弹 toast——状态住在格子里。

## 3. 交互规格（矩阵）

| 操作 | 交互 | 反馈 |
|---|---|---|
| 建连 | 点空格 → 原位浮窗（写入方式 / 同名冲突）→ 连接并同步 | 格子描边生长+填充 250ms；toast 一次 |
| 断开 | 悬停已连格 → ✕ → 原位确认（保留文件 / 清理受管） | 填充淡出 150ms |
| 立即同步 | 悬停已连格 → ↻ | 单次扫光 900ms；结果写入格子状态 |
| 暂停/恢复 | 悬停已连格 → ⏸ | 格子降透明度 + 「已暂停」 |
| 失败 | 自动 | 黄底常亮 + 悬停原因 + 下次源变化自动重试 |
| 聚焦 | 点行名/列头 | 高亮整行/列（其余降透明），看单向关系 |
| 自动同步 | 无交互 | 格内单次扫光，完成即静默 |

## 4. 数据模型泛化

```sql
-- dir_bindings 泛化为 source_bindings（旧表迁移：dir 行 → source_kind='dir'）
CREATE TABLE IF NOT EXISTS source_bindings (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  source_kind TEXT NOT NULL,            -- 'dir' | 'repo'
  source_id INTEGER NOT NULL,           -- local_dirs.id | sources.id
  target_id INTEGER NOT NULL,           -- targets.id（kind='skills_dir'）
  mode TEXT NOT NULL DEFAULT 'copy',
  enabled INTEGER DEFAULT 1,
  created_at TEXT NOT NULL,
  last_sync_at TEXT,
  last_result TEXT,
  UNIQUE(source_kind, source_id, target_id)
);
```

- 源条目集合：`dir` → registry_items.dir_id=source_id；`repo` → registry_items.source_id=source_id
- worker 触发源扩展：目录变化（hub:localdirs）与远仓拉取落库（hub:registry / sources 范围）都进入绑定跟随
- 移除源（删除目录/删除远仓）→ 自动解绑（工具内文件保留，同现有语义）

## 5. 分期

- **M1**：source_bindings 泛化迁移 + 矩阵视图（连接/断开/立即同步/失败态）+ 远仓行 + worker 扩展 + 各页卡片连接色点跳转
- **M2**：软链接模式、共享 target 明示强化、暂停、手动同步按钮位、冲突详情浮层
- **P2**：MCP 矩阵页签（mcp 目标绑定）、条目级排除、绑定健康总览

## 6. 验收标准

1. 矩阵一屏可见全部绑定关系；任何建连/断开 ≤2 次点击（点格 + 确认）；
2. 远仓建连 → 已拉取条目全量同步；上游更新 → 拉取 → ≤5s 分发到绑定目标；
3. 双向视角等价（行聚焦/列聚焦）；共享 target 双工具同时生效且 UI 明示；
4. 动效全部走统一曲线与时长档；自动同步无 toast；
5. 判据：repo 绑定建连/同步/断开、worker 对 repo 源的三态传播、矩阵 API。
