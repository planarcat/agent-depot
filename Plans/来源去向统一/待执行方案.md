## 1. 背景与目标

会话、记忆两个页签已统一为「左=数据来源 / 中=内容 / 右=数据去向」的三栏模型。
Skills 与 MCP 页签目前左栏只有「本地·手动 + 远程仓库」两类来源。本次把两页签对齐同一模型，并新增第三类来源：**工具**——从工具中反向提取 skill / MCP 收编进本地库，让「用户在某个工具里手动装的内容」也能进入 hub 的统一分发体系。

## 2. 三类数据来源（左栏）

| 来源 | 含义 | 现状 |
| --- | --- | --- |
| 本地 · 手动 | 本地库中手工创建的条目 | 已有 |
| 远程仓库 | Git 源拉取的条目 | 已有 |
| **工具（新增）** | 某工具 `skills_dir` / `mcp_config` 中实际存在的内容 | 新建 |

工具来源的关键语义——**反向提取**：

- 逐个列出工具内实际存在的条目（skills 目录的每个子目录 / mcp 配置的每个 server）
- 与本地库（registry）对齐去重，条目名做键，分三态：
  - `synced` 已收编：同名且内容一致（skills 比目录树 hash，mcp 比 config JSON hash）
  - `diff` 有差异：同名但内容不同（本地库与工具各改各的，需人工裁决）
  - `local_only` 未收编：本地库没有 → 可一键「提取到本地库」
- 同一条目跨多工具出现：列表按条目去重，条目上标记「出现在哪些工具」

## 3. 布局（与会话/记忆同构）

```
┌─ 左：数据来源 ─────────┐ ┌─ 中：条目内容 ─────────┐ ┌─ 右：数据去向 ────────┐
│ 全部                    │ │ 详情 / CRUD / 批量      │ │ 各启用工具            │
│ 本地 · 手动             │ │ （基本不动）            │ │ 条目安装状态          │
│ 远程仓库（各源）        │ │                         │ │ 写入 / 更新按钮       │
│ 工具（各启用工具）      │ │                         │ │ （现状保留，视觉统一）│
│  · 探不到目录→置灰      │ │                         │ │ 不可写→隐藏           │
└────────────────────────┘ └─────────────────────────┘ └───────────────────────┘
```

能力探测语义与记忆线一致：工具目录探不到 → 左栏置灰；无写入路径 → 右栏隐藏；受设置页启停总开关控制。

## 4. 数据流（提取）

```
工具文件（skills_dir/<名>/ 或 mcp_config 的 server 定义）
   → 扫描对比 registry → 三态清单
   → 「提取到本地库」（仅 local_only / diff）
   → 复制内容为 manual 条目（与源仓库拉取同权，可再分发）
   → 工具内文件保留不动（视为已安装）
   → 之后该条目走正常分发体系（改本地库 → 写回各工具）
```

## 5. 后端新增 API

- `GET /api/skills/tool-items?tool=<id>` → `{items:[{name, state, tools:[...], path}]}`
- `POST /api/skills/extract` `{tool, names:[...]}` → 逐条收编（已收编跳过；diff 覆盖本地库并以工具内容为准）
- MCP 同构：`GET /api/mcp/tool-items?tool=<id>`（解析各 format：mcpServers / mcp.servers / TOML）
  `POST /api/mcp/extract` `{tool, names:[...]}`
- 去重键=条目名；内容比对=skills 用 `fsutil.tree_hash`，mcp 用归一化 config 的 hash（复用 registry 逻辑）
- 全部操作记 ops 台账（与现有 CRUD 一致）

## 6. 前端改动

- `skills.js` / `mcp.js` 左栏来源区加「工具」分组；选中工具来源 → 中栏列表切换为工具内条目（含三态徽章 + 未收编「提取」按钮 + 批量提取）
- 右栏视觉/交互统一为能力探测语义（与 memory.js 同款样式）

## 7. 分期

- **T1** Skills：tool-items / extract API + 左栏工具来源 + 提取交互
- **T2** MCP：同构 API + 左栏 + 提取（TOML/config 多格式解析）
- **T3** 右栏视觉统一 + 全页签回归走查（含会话/记忆不回归）

## 8. 默认决策（可改）

1. 提取后工具内文件**保留不删**（视为已安装，后续由分发体系接管）
2. 去重以**条目名**为键；`diff` 态提取时以**工具内容为准**覆盖本地库（工具是最新事实来源）
3. 停用工具不显示（与记忆线一致）
4. 提取产生 manual 条目，可正常分发到其他工具
