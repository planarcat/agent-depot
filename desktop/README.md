# Agent Depot · 桌面壳（Tauri）

原生 macOS 窗口壳：启动时**确保本地服务（127.0.0.1:8317）在跑**（幂等，未运行则执行仓库 `./run.sh`），
然后用系统 WKWebView 加载控制台；服务不可用时显示内置提示页。

- 运行时零第三方依赖：渲染用系统 WebKit；产物为单文件原生二进制（约 10 MB）
- 构建期依赖：Rust 工具链（~/.cargo）+ tauri-cli（本目录 node_modules），仅重打包时需要
- 关窗 ≠ 停服务；停服务用仓库根 `./stop.sh`（与薄壳时代语义一致）
- 本机实测：tauri 2.11.6 · Rust 1.98.1 · 不再依赖浏览器窗口

## 菜单栏 / 启动设置（v0.6.0）

设置入口：主窗口「设置 → 桌面」。改动即时生效并写入
`~/Library/Application Support/local.planarcat.agent-depot/desktop.json`。

| 设置 | 行为 |
|---|---|
| 开机启动 | 写入 `~/Library/LaunchAgents/local.planarcat.agent-depot.plist`（`RunAtLoad` + `--silent`），关闭即卸载删除 |
| 菜单栏挂载 | 菜单栏常驻图标；**关窗 = 隐藏**，点图标/菜单「显示主窗口」再打开；默认开启 |
| 静默启动 | 启动后只挂菜单栏、不显示窗口（依赖菜单栏挂载；关掉菜单栏会自动关掉静默启动）；下次启动生效 |
| 显示 Dock 图标 | 窗口打开时始终显示；关闭主窗口后（菜单栏挂载开启）调用 `set_dock_visibility(false)` 从 Dock 移除，点菜单栏图标恢复 |

菜单栏菜单：显示主窗口 / 打开设置… / 退出 Agent Depot。左键点图标 = 显示主窗口，右键 = 菜单。
手动指定静默启动：`open -a AgentDepot --args --silent`（自动启动的 LaunchAgent 已带该参数）。

> IPC 说明：控制台页面从 `http://127.0.0.1:8317` 加载，属于 remote URL；
> `src-tauri/capabilities/default.json` 通过 `remote.urls` 放行该来源，但**应用命令仍要过 ACL**：
> 新命令必须在 `build.rs` 的 `AppManifest::commands([...])` 登记，并把生成的
> `allow-<命令名>` 加进 capability 的 `permissions`——否则页面调用会报
> `Command xxx not allowed by ACL`（0.6.0 实测）。生成物在 `permissions/autogenerated/`，随源码进仓。

## 开发版 / 正式版隔离（v0.6.1）

两套客户端**设置、开机启动项、WebView 存储都不共享**，可以同时安装：

| | 正式版 | 开发版 |
|---|---|---|
| 安装包 | `~/Applications/AgentDepot.app` | `~/Applications/AgentDepot-Dev.app` |
| bundle id | `local.planarcat.agent-depot` | `local.planarcat.agent-depot.dev` |
| 构建 | `bash scripts/make-app.sh` | `bash scripts/make-app-dev.sh` |
| 桌面设置文件 | `desktop.json` | `desktop-dev.json` |
| LaunchAgent | `local.planarcat.agent-depot.plist` | `local.planarcat.agent-depot-dev.plist` |
| 默认菜单栏 | 开启 | 关闭（避免调试时两个托盘） |
| 本地偏好（localStorage） | 正式版 WebView 存储 | 独立 bundle → 独立存储 |
| 服务数据 | `~/.agent-depot`（`AGENT_DEPOT_PROFILE=release`） | `~/.agent-depot-dev`（`AGENT_DEPOT_PROFILE=dev`） |

- 开发版由**独立 bundle id** 识别（`…agent-depot.dev`）；纯 `cargo run` / debug 二进制按 `cfg!(debug_assertions)` 走开发版。
  服务数据目录由 `AGENT_DEPOT_PROFILE`（dev/release）选择，由桌面壳按自身 profile 传给 `run.sh`。
- `./dev <分支>` 启动 dev 库并优先打开 `AgentDepot-Dev.app`；`./dev <分支> --prod` 打开正式版。
- 两版共用 8317 端口：同一时刻只建议运行一个服务实例；切换用 `./dev` / `./dev ... --prod`。

## 构建 / 重装

```bash
bash scripts/make-app.sh     # 仓库根执行：编译 + 安装到 ~/Applications/AgentDepot.app（旧版自动移入废纸篓）
```

仅构建（不安装）：

```bash
cd desktop
PATH="$HOME/.cargo/bin:$PATH" ./node_modules/.bin/tauri build
# 产物：src-tauri/target/release/bundle/macos/Agent Depot.app
```

## 工作原理

1. `src-tauri/src/main.rs` 启动探测 `127.0.0.1:8317`；未运行则 `bash -c "cd <repo> && ./run.sh"`（幂等），随后最多轮询 6s
2. 服务可用 → 创建窗口（1480×960）加载 `http://127.0.0.1:8317`
3. 服务不可用 → 加载内置提示页（前端资源嵌入于二进制，源在 `ui/index.html`）
4. 仓库路径默认 `~/Documents/Projects/@planarcat/agent-depot`，可用环境变量 `AGENT_DEPOT_REPO` 覆盖

## 修改指南

| 想改什么 | 改哪里 |
|---|---|
| 窗口标题 / 尺寸 | `src-tauri/src/main.rs`：`.title()` / `.inner_size()` |
| 应用图标 | 替换 `assets/icon-source.png`（1024×1024；可用 `assets/gen_icon.py` 重新生成），然后 `./node_modules/.bin/tauri icon assets/icon-source.png` |
| 端口 | `src-tauri/src/main.rs` 的 `PORT`（与 `run.sh` 的 `HUB_PORT` 保持一致） |
| 菜单栏菜单项 / 托盘事件 | `src-tauri/src/main.rs`：`ensure_tray()` |
| 桌面设置默认值 / 持久化 | `src-tauri/src/main.rs`：`DesktopSettings` / `settings_path()` |
| 设置页 UI | `web/src/views/settings.ts`（通用 / 桌面两个 pane） |
| 版本号 | `desktop/package.json` · `src-tauri/Cargo.toml` · `src-tauri/tauri.conf.json` 三处同步 |
| 提示页文案 | `ui/index.html` |

## 国内网络（构建镜像）

- Rust 工具链：`RUSTUP_DIST_SERVER=https://rsproxy.cn`、`RUSTUP_UPDATE_ROOT=https://rsproxy.cn/rustup`
- crates 源：`~/.cargo/config.toml` → rsproxy sparse（`sparse+https://rsproxy.cn/index/`）
- tauri-cli：`npm --registry=https://registry.npmmirror.com install`
