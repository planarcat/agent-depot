原型 · 连接中心 —— 磁贴基底 ×4 变体

以「卡片磁贴（每源一卡 + 工具药丸）」为参考基底的四个演进方向。全部可交互、双向（源卡看工具 / 工具卡看来源）、远仓与目录同权。统一动效：连接=药丸弹性入场、抽屉=高度展开 250ms、状态=文字徽章切换。

V1 · 抽屉版操作收进卡内 · 零弹窗

连接/断开/暂停全部发生在卡片内部：点「＋ 连接工具」在卡内展开工具抽屉（含路径与建连按钮）；药丸点一下即断开。最克制，边界最清晰。

动效抽屉展开 = grid 0fr→1fr（250ms）；建连药丸弹性入场；暂停状态 = 药丸尾缀「已暂停」 边界一卡一抽屉，抽屉里只列「未连接」的工具——已连接的以药丸形式长驻卡面

V2 · 双区状态版每个绑定有自己的生命周期

把「连接」当成卡内的小资源管理：每条绑定一行（工具 · 模式 · 状态 · 操作），状态一眼可见、逐条可控（暂停/断开/立即同步）。适合绑定多、要看健康度的场景。

状态语义✓ 已同步（绿）· ⏸ 已暂停（黄）· ✕ 上次失败（红，悬停看原因） 操作行尾 [⏸][↻][✕]；「＋ 连接工具」抽屉展开未连接的工具

V3 · 工具视角版反向：每张卡 = 一个工具

需求③的「反过来」：卡 = 工具（色点 + skills 路径 + 接收了 n 个源），卡上药丸 = 已接入的源（目录/远仓各带角标）；「＋ 添加来源」抽屉列未接入的源。与 V1 完全对称。

对称性V1 看源（一个目录分发到哪几个工具）；V3 看工具（一个工具收了哪些源）——两侧信息等价，入口按当下心智任选 注意Codex / OpenCode 共享 ~/.agents/skills：一次「添加来源」两卡同时出现药丸（原型为演示各自独立展示）

V4 · 主从版零弹窗 · 全部内联（推荐）

左列源清单（含远仓，角标可筛选），右侧选中源的绑定明细表（工具/模式/最近同步/操作）+「＋ 连接工具」内联抽屉 + 最近同步记录。整页无一个弹窗，操作路径最短。

动效选中 = 描边圈（与全局选中语言一致）；连接抽屉同 V1；最近同步 = 静默文字流 推荐理由「简单直接、不要下钻、双向」三条件同时满足：左边换源、右边看/改绑定，无任何弹层
