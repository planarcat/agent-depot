E · 自动化规则风绑定 = 一句可读的规则

把每条绑定渲染成一句自然语言规则：「当 [源] 内容变化时 → 自动同步到 [目标]（复制）」。心智最清晰——绑定即自动化规则，暂停 = 规则停用。[＋ 新规则] 三步内建规则。

＋ 新规则 当 内容变化时 → 自动同步到 （）
规则语言开关 = 暂停/恢复；[立即同步] 手动触发；删除规则保留工具内文件 试一下改选源/目标/模式 → 创建规则 → 规则卡出现并可开关

F · 双栏拖拽直接操纵 · 拖卡建连

左栏源池、右栏工具池：**把源卡拖到工具卡上**即建连（拖到已连工具 = 断开）。最直接的实体操作，双栏各自成池便于浏览。

源 · 目录 / 远程仓库（拖我 →）
工具目标（拖到卡片上建连 / 再拖一次断开）
操作拖「源」卡 → 落到右栏某工具卡上 = 建连（工具卡 ⇐ 计数 +1）；再拖一次 = 断开 辅助源卡上显示它已连接的工具色点（与线上目录卡一致）；工具卡显示接收的源数量

G · 中心轨道（驾驶舱）空间化 · 一源多工具最直观

选中一个源居于中心，工具排布在轨道环上：已连接 = 实心药丸 + 连线，未连接 = 幽灵占位。点幽灵 = 建连、点实心 = 断开。一眼看清「这个源覆盖了哪些工具」。

操作左侧选源（切中心）→ 点轨道上的幽灵工具 = 建连、点实心 = 断开；连线实时重画 动效建连 = 连线从中心生长 + 药丸变实；断开 = 线淡出；无接线的方向暗示扩展空间

H · 活动流（运维视角）绑定健康 + 同步时间线

绑定以「健康卡」呈现（每工具：已接源数 / 最近同步），下方是同步活动流时间线。适合绑定数量多之后的日常运维；建连/断开仍走其它方案，此处专注「看得见在发生什么」。

定位作为其它方案的附属页签（连接中心 → 「活动」）：不承担建连，专注健康与回放 试一下点「模拟一次自动同步」→ 时间线推入新事件 + 健康卡更新
