原型 · 目录卡绑定交互 —— 动效演进 ×4

基于线上 .tcard 卡片本体（数量角标 / 色块 / 名称 / →色点 / 悬停浮起 全部保留），只演进绑定相关的交互与动效。每个变体都可交互，悬停/点击试试。

A · 悬停连接排演进最小 · 复用交叉淡化

默认态与线上完全一致（→色点）。悬停卡片时，色点**交叉淡化**为「连接排」：每个已连工具变成小胶囊（可 ✕ 断开），末尾 [＋] 建连。零新增占位。

保留的动效悬停浮起（-2px + 阴影）· 数量角标交叉淡化 · 选中描边 演进的动效色点 ⇄ 连接排 = 交叉淡化 150ms（与数量角标同一手法）；建连 = 胶囊弹性入场 260ms spring；断开 = 即时消失 试一下悬停 agent-skills 卡 → 胶囊排出现 → 点 [＋] 建连 → 点胶囊 ✕ 断开

B · 原位抽屉卡片向下展开 · 状态逐条可见

点卡片左下「→n」标记，卡片向下原位展开抽屉：每条绑定一行（工具 · 模式 · 状态 · 暂停/断开），底部列出可建连的其余工具。状态逐条可见，适合绑定多的源。

动效展开 = grid-rows 0fr→1fr 250ms（邻居平滑让位，无跳变）；行入场 = 弹性 260ms 逐行出现；暂停 = 状态徽章文字切换（黄） 试一下点 lingchuang-skills 卡的「→1」→ 抽屉展开 → 点行尾 ⏸ / ✕

C · 状态徽标→色点升级为活的状态胶囊

左下标记从「静态色点」升级为「状态胶囊」：平时=色点（无占位变化）；同步中=青底扫光「↻ 同步中」；失败=黄底「!」悬停看原因。动效只表达**正在发生的事**。

动效同步中 = 青底扫光循环（只在同步期间存在，完成即静默回到色点）；失败 = 黄底常亮 + 悬停原因（无动效，状态不打扰） 试一下点「触发一次同步」→ agent-skills 的胶囊进入扫光态 → 2s 后自动回到色点

D · 建连浮层＋号锚定卡片 · 一层完成建连

连接排末尾的 [＋] 点击后，从锚点弹出一层工具选择浮层（色点+名+路径+连接），建连完成后目标色点**弹入**连接排。建连全程不离卡片。

动效浮层 = 从锚点缩放入场 150ms；建连成功 = 新色点弹性入场 260ms spring；其余卡片无感知 试一下悬停默认目录卡 → 点连接排末尾 [＋] → 浮层里点「Codex CLI」建连
